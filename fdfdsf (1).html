Installation guide

Set up CapeOS on your Raspberry Pi.

Follow these steps in order. The download stays available above whenever you need it.

Part 1 · Prepare the microSD card

  1. Download and install Raspberry Pi Imager.
  2. Insert your microSD card into your computer.
  3. In Imager, choose your Pi model under Device, Raspberry Pi OS (64-bit) with desktop under OS, and your card under Storage.
  4. Click Next, then Edit Settings. Set a username and password, configure Wi-Fi, and enable SSH only if you plan to use the network transfer option.
  5. Save the settings and write the card. When it finishes, put the card in your Pi, connect a monitor, keyboard and mouse, then plug in power.
  6. Complete the first-boot setup to reach the Raspberry Pi desktop.

Part 2 · Transfer the ZIP to your Pi

Option A · USB stick (easiest)

  1. Copy RASPBERRYPI.zip onto a USB stick from your Mac or Windows computer.
  2. Plug the stick into the Pi. Open the file window and copy the ZIP into your Home folder.

Option B · Network transfer (SSH required)

Replace yourusername with the username you created. Run the command from the computer where the ZIP is saved.

Windows PowerShell

scp "$HOME\Downloads\RASPBERRYPI.zip" yourusername@raspberrypi.local:~/

Mac Terminal

scp ~/Downloads/RASPBERRYPI.zip yourusername@raspberrypi.local:~/

If raspberrypi.local does not work, replace it with your Pi's IP address.

Part 3 · Install CapeOS on the Pi

  1. On the Pi, open the file manager, find RASPBERRYPI.zip, right-click it and choose Extract Here.
  2. Open Terminal and run these commands one at a time:
cd ~/CapeOS-RaspberryPi
chmod +x install.sh uninstall.sh
./install.sh

If asked for your password to install Chromium, type it and press Enter. The password will not appear as you type. When installation finishes, look for CapeOS in the menu or run ~/CapeOS/capeos-start.

The extracted folder is expected to be named CapeOS-RaspberryPi. If your ZIP extracts to a differently named folder, use that folder name in the first Terminal command.

Using CapeOS

  • CapeOS opens full screen. Press Alt + F4 to close it.
  • To open it in a normal window, run:
~/CapeOS/capeos-start --window
  • By default, CapeOS starts each time you log in.
  • To install without automatic startup, use ./install.sh --no-autostart instead of the standard install command.
  • To start CapeOS at boot, run sudo raspi-config, then choose System Options → Boot / Auto Login → Desktop Autologin.
  • To remove CapeOS, run:
~/CapeOS/uninstall.sh

Troubleshooting

“Permission denied” on install.sh
Run chmod +x install.sh first.

Blank screen or nothing opens
Run ~/CapeOS/capeos-start --window and check the Terminal output.

Port already in use
Run CAPEOS_PORT=9000 ~/CapeOS/capeos-start.
